# Data Visualization dell'incremeneto nell'uso delle auto elettriche in Italia e in Europa
Progetto universitario realizzato per il corso di Visualizzazione scientifica (A.A. 2025/2026) presso l'Università degli Studi di Milano. 
Questa repository contiene notebook e risorse per analizzare l'andamento delle vendite delle autovetture elettriche e delle relative inftrastrutture. I dati provengono da fonti ufficiali di **ISTAT**, **EUROSTAT** e **MOTUS-E** vengono rielaborati per generare grafici e visualizzazioni.

## Struttura del progetto

- **script/** – Notebook Jupyter con le analisi e le visualizzazioni
- **data/** – Dataset originali in formato CSV
- **resources/** – Immagini e documentazione di riferimento
- **presentazione/** – Diapositive e link alla presentazione

## Utilizzo

1. Creare un ambiente Python (versione 3.9 o superiore)
2. Installare le dipendenze principali:
   ```bash
   pip install pandas numpy matplotlib urllib seaborn
   ```
3. Avviare Jupyter e aprire i notebook nella cartella `code/`:
   ```bash
   jupyter notebook
   ```
4. Eseguire i notebook per riprodurre le analisi e i grafici

Per consultare la presentazione interattiva visitare il link indicato in `presentazione/referece.txt`.
